3. Tipologie di dati trattati / Types of Data Processed

Italiano

WaveStream memorizza e tratta esclusivamente dati locali sul dispositivo dell’utente. Nessun dato personale viene inviato a server del titolare o utilizzato per finalità di marketing o profilazione.

  • Credenziali IPTV (username, password, URL server) – salvate nel database locale (Room DB) per consentire l’autenticazione presso il provider IPTV configurato dall’utente.
  • Playlist (URL M3U/Xtream, nome, tipo) – salvate nel database locale per permettere il caricamento dei canali.
  • Profili utente (nome profilo, avatar scelto) – salvati nel database locale per permettere la gestione multi-profilo.
  • Cronologia visione (contenuti visti, progresso di riproduzione) – salvata localmente per la funzione “Continua a guardare”.
  • Preferiti (film/serie preferiti) – salvati localmente, funzionalità opzionale.
  • API keys opzionali (TMDB, OMDb) – salvate in EncryptedSharedPreferences sul dispositivo, utilizzate solo per recuperare metadati (copertine, descrizioni, valutazioni).
  • Credenziali OpenSubtitles opzionali (username, password) – salvate in EncryptedSharedPreferences sul dispositivo, utilizzate solo per ottenere sottotitoli.
  • Preferenze dell’app (tema, colore accento, lingua sottotitoli, ecc.) – salvate tramite DataStore locale.
  • Backup JSON – esportazione manuale di tutti i dati sopra indicati, in un file scelto dall’utente tramite il selettore di file di Android (SAF).

WaveStream non raccoglie né tratta posizione GPS, rubrica contatti, galleria foto/video/audio (salvo l’eventuale APK di aggiornamento), ID pubblicitari, né effettua tracciamento analitico o profilazione utenti.

English

WaveStream stores and processes data locally on the user’s device only. No personal data is sent to the controller’s servers or used for marketing or profiling purposes.

  • IPTV credentials (username, password, server URL) – stored in the local Room database to authenticate against the IPTV provider configured by the user.
  • Playlists (M3U/Xtream URL, name, type) – stored in the local database to load channels.
  • User profiles (profile name, selected avatar) – stored locally to enable multi-profile management.
  • Watch history (viewed items, playback progress) – stored locally for the “Continue watching” feature.
  • Favorites (favorite movies/series) – stored locally, optional feature.
  • Optional API keys (TMDB, OMDb) – stored in local EncryptedSharedPreferences, used only to retrieve metadata (covers, descriptions, ratings).
  • Optional OpenSubtitles credentials (username, password) – stored in local EncryptedSharedPreferences, used only to obtain subtitles.
  • App preferences (theme, accent color, subtitle language, etc.) – stored via local DataStore.
  • JSON backup – manual export of all data listed above to a file chosen by the user through the Android Storage Access Framework.

WaveStream does not collect or process GPS location, contacts, media gallery (except for a downloaded update APK), advertising IDs, nor does it perform analytics tracking or user profiling.

6. Terze parti e comunicazioni tecniche / Third Parties and Technical Communications

Italiano

WaveStream non vende né condivide dati personali con terze parti per finalità di marketing o profilazione. Le uniche comunicazioni verso terzi sono di natura tecnica, necessarie all’erogazione delle funzionalità richieste dall’utente.

  • Server IPTV dell’utente: richieste HTTP(S) verso gli URL della playlist/portale Xtream inseriti dall’utente, per la riproduzione dei contenuti e la gestione dell’EPG.
  • TMDB (api.themoviedb.org): invio di titoli o identificativi dei contenuti per recuperare copertine, descrizioni e metadati (senza invio di credenziali IPTV o dati identificativi dell’utente).
  • OMDb (www.omdbapi.com): invio di titolo o ID film per recuperare voti e informazioni aggiuntive (senza dati personali dell’utente).
  • OpenSubtitles (api.opensubtitles.com): invio di titolo e lingua, ed eventualmente credenziali dell’account OpenSubtitles, per scaricare sottotitoli.
  • Firebase Realtime Database (wavestream-d3972-default-rtdb.europe-west1): lettura del nodo app_update per verificare la disponibilità di una nuova versione, senza invio di dati utente.
  • GitHub Releases: download dell’APK di aggiornamento quando richiesto dall’utente.

English

WaveStream does not sell or share personal data with third parties for marketing or profiling purposes. The only communications to third parties are technical and necessary to provide the features requested by the user.

  • User’s IPTV servers: HTTP(S) requests to the M3U/Xtream portal URLs entered by the user, to play content and manage the EPG.
  • TMDB (api.themoviedb.org): sending titles or identifiers to retrieve covers, descriptions and metadata (no IPTV credentials or user-identifying data are sent).
  • OMDb (www.omdbapi.com): sending movie titles or IDs to retrieve ratings and additional information (no personal user data are sent).
  • OpenSubtitles (api.opensubtitles.com): sending titles and language, and optionally OpenSubtitles account credentials, to download subtitles.
  • Firebase Realtime Database (wavestream-d3972-default-rtdb.europe-west1): reading the app_update node to check for new versions, without sending user data.
  • GitHub Releases: downloading an updated APK when requested by the user.

7. Modalità di trattamento e sicurezza / Processing Methods and Security

Italiano

I dati locali sono trattati tramite le funzionalità standard del sistema operativo Android e delle librerie dell’app, con logiche strettamente correlate alle finalità descritte. Il titolare adotta misure tecniche e organizzative adeguate per proteggere i dati personali, in linea con il GDPR.[web:1][web:3][web:10]

  • Cifratura del traffico verso servizi terzi tramite HTTPS.
  • Cifratura delle API keys e delle credenziali opzionali in EncryptedSharedPreferences (AES-256, gestito dal sistema).
  • Disattivazione del backup Android di sistema (allowBackup="false").
  • Assenza di sistemi di analytics, advertising o tracciamento di terze parti.

Le password dei provider IPTV sono attualmente memorizzate in chiaro nel database locale; si raccomanda all’utente di proteggere l’accesso fisico al dispositivo e ai profili Android utilizzati.

English

Local data is processed using Android OS standard features and app libraries, strictly in line with the purposes described. The controller adopts appropriate technical and organizational measures to protect personal data, in accordance with the GDPR.[web:1][web:3][web:10]

  • Encryption of traffic to third-party services via HTTPS.
  • Encryption of API keys and optional credentials in EncryptedSharedPreferences (AES-256, managed by the system).
  • System Android backup disabled (allowBackup="false").
  • No analytics, advertising or third-party tracking systems.

IPTV provider passwords are currently stored in plain text in the local database; users are advised to protect physical access to the device and the Android profiles used.
